# 直播切片工作台

面向中文单人口播直播的 Electron 桌面工具。导入直播回放和逐字稿后，可以生成候选、对照原话审核、调整剪辑并导出发布素材。文本选片工作台也支持先处理逐字稿，再将标注稿交给剪辑人员。

## 能做什么

- 导入本地视频和 SRT、VTT、TXT 或 DOCX 逐字稿，支持 CSV 批量建任务。纯文本的时间码可能需要人工核对。
- 使用 DeepSeek 生成候选，结合账号规则、内容质量和原话时间码审核。候选数量取决于素材和审核结果。
- 编辑候选段落、开头、字幕和裁剪，使用 FFmpeg 生成竖屏预览和成片，导出视频、封面和发布文案。
- 文本选片支持从部分听悟、飞书妙记及千问分享链接读取内容，并可将审核后的标注稿导出到已授权的飞书文档或文件夹。分享链接的可用性取决于来源和访问权限。
- 任务、账号配置和审核历史保存在本机，可选配飞书交付或团队更新。

## 从源码运行

准备 Node.js 24 LTS。Windows PowerShell 中如果执行策略阻止 npm 脚本，可把命令中的 `npm` 换成 `npm.cmd`。

```sh
npm ci
npm run dev
```

在工作台的「本地设置」选择工作目录，按需配置 DeepSeek API Key 和飞书自建应用。创建一个账号后，导入一段你有权使用的视频及其逐字稿。建议从 SRT 或 VTT 开始，可以直接用时间码对照原话。CSV 字段示例见 [批量导入模板](samples/batch-import.csv)。

在账号的「内容选题原则」里填写自己的筛选规则。首行填写 `升学决策选题预设` 可启用额外的本地升学话题筛选，其余行可以继续写账号规则。

需要样片本地转写或字幕精确定位时，可安装带 `faster-whisper` 的 Python 环境，将 `LIVE_CLIP_PYTHON` 设置为解释器的绝对路径，将 `LIVE_CLIP_WHISPER_MODEL` 设置为含 `model.bin` 的模型目录。如果依赖安装在独立目录，可通过 `LIVE_CLIP_MEDIA_TOOLS` 指定该目录。常规的本地视频加带时间码逐字稿流程不需要 Python。

## 测试与构建

```sh
npm test
npm run build
```

仓库带有 Windows 和 macOS 的打包配置。打包前应按目标系统验证依赖和启动流程。发布包含 FFmpeg 等第三方组件的安装包时，需核对所用二进制对应的许可证及分发义务。

## 数据与外部服务

- 社区版使用操作系统应用数据目录下的 `live-clip-workbench-community`，SQLite 数据库为 `workbench.sqlite`。
- 配置模型后，选片和文案功能会向所配置的服务发送逐字稿及相关账号、样片文字和审核上下文。预览与渲染在本机执行。
- 听悟、千问、飞书导入及飞书导出会访问对应服务。使用这些功能需要拥有素材访问或文档写入权限。
- 模型和飞书凭证通过应用设置录入。分享日志或问题截图前，请检查其中的凭证、带授权参数的链接和原始逐字稿。
